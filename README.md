# Marketing Performance Analysis Dashboard | Power BI

## Project Overview

This Power BI dashboard provides a comprehensive analysis of digital marketing performance across multiple social media platforms including Facebook, Instagram, and Pinterest.

The dashboard evaluates marketing effectiveness using conversion metrics, campaign spending, engagement indicators, CTR trends, and platform performance to support data-driven marketing decisions.

---

## Business Objective

The main goal of this project is to identify:

- Which marketing channel performs best
- Conversion efficiency across platforms
- Spending effectiveness
- Audience engagement behavior
- High-performing campaigns and locations
- Device impact on conversion performance

---

# Key Insights

- Instagram shows strong engagement and conversion performance.
- Facebook generates high impressions and consistent campaign activity.
- Pinterest achieves conversions with relatively lower spending.
- CTR changes across platforms indicating different audience behavior.
- Device type affects campaign performance significantly.

---

# Business Recommendations

Based on dashboard findings:

- Increase investment in high-converting channels.
- Optimize campaigns with lower CTR performance.
- Improve targeting strategies by device type.
- Focus on top-performing locations.
- Monitor campaign efficiency continuously.
